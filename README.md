# PW Academy K8 CRM

A web-based CRM dashboard for:

- Order Punching
- Order Processing
- Dispatch Tracking
- Delivery Monitoring
- Inventory Management
- Google Sheets Sync
- Excel Export

## Features

- OTP Login Screen
- Dashboard Analytics
- Inventory Management
- Sample Request Tracking
- Google Sheets Integration
- Excel Export
- Courier Tracking

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Chart.js
- SheetJS (Excel Export)

## Deployment

This project can be deployed directly on:

- GitHub Pages
- Netlify
- Vercel
